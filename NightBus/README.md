# NightBus

Учебный игровой проект для ZX Spectrum 128K на Z80 assembler.
Разработка игры и изучение Z80 идут одновременно: в проект не добавляется «магический» код, который мы не разобрали хотя бы на практическом уровне.

## Окружение

- SjASMPlus
- Fuse
- GNU Make
- Git

## Сборка

```bash
make
```

Результат:

```text
build/nightbus.tap
```

TAP содержит BASIC-loader и машинный код, который загружается по адресу `$8000`.

## Запуск

```bash
./r
```

`r` проверяет инструменты, собирает проект и запускает `build/nightbus.tap` в Fuse в режиме ZX Spectrum 128K.

## Структура

```text
NightBus/
├── Makefile
├── README.md
├── r
├── versions.md
├── build/          # генерируется, в Git не хранится
└── src/
    ├── main.asm    # код игры
    └── tape.asm    # TAP + BASIC-loader
```

## Общие инструменты ZX

`ZX` — общий Git-репозиторий для нескольких независимых подпроектов.
Общие скрипты `a` и `appr` лежат в корне `ZX`, но запускаются из каталога конкретного подпроекта:

```bash
../a
../appr
```

У каждого подпроекта свои `versions.md`, `README.md`, сборка и версия.
