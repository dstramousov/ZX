# Versions

## v0.0.0 -> v0.0.1

- Init repo

## v0.0.1 -> v0.0.2

- Подготовлена общая структура ZX как репозитория с независимыми подпроектами.
- Скрипт `a` теперь автоматически берёт имя текущего подпроекта и создаёт его архив по версии из локального `versions.md`.
- `appr` явно работает из корня подпроекта и показывает, чей `versions.md` используется для коммита общего ZX-репозитория.
- Добавлен `r`: сборка NightBus и запуск TAP в Fuse как ZX Spectrum 128K.
- В TAP добавлен BASIC-loader для автоматической загрузки машинного кода по адресу `$8000`.
- Добавлены README и корневой `.gitignore` для артефактов сборки и локальных архивов.

## v0.0.2 -> v0.0.3

- `a` и `appr` снова можно запускать прямо из корня `ZX`.
- Если подпроект пока один, он выбирается автоматически; при нескольких подпроектах используется `./a <project>` / `./appr <project>`.
- Сохранён запуск общих скриптов из корня подпроекта через `../a` / `../appr`.
- Git-команды `appr` теперь явно выполняются относительно корня общего репозитория `ZX`.

## v0.0.3 -> v0.0.4

- Для быстрого цикла разработки добавлен snapshot `build/nightbus.sna`.
- `sjasmplus` создаёт SNA напрямую из `src/main.asm` в режиме ZX Spectrum 48K.
- `./r` теперь запускает snapshot напрямую в Fuse, без зависимости от BASIC/TAP autoload.
- TAP остаётся частью обычной сборки и предназначен для запуска на реальном ZX Spectrum / ZX Evolution.

## v0.0.4 -> v0.0.5

- NightBus окончательно переведён на целевую платформу Sinclair ZX Spectrum 128K.
- 48K/SNA dev-запуск удалён: сборка снова использует TAP, чтобы не зависеть от неоднозначности 128K SNA в Fuse.
- `r` явно использует `128-0.rom` и `128-1.rom`, проверяет их наличие и запускает Fuse как машину `128`.
- Для автоматического запуска TAP включён 128K phantom typist в режиме меню; окно Fuse запускается с масштабом `3x`.
- Добавлены `memory.asm` и `paging.asm`: зафиксирована карта памяти и базовая процедура переключения RAM-банков через порт `$7FFD`.
- README приведён в соответствие с новой 128K-архитектурой.

## v0.0.5 -> v0.0.6

- Исправлен заголовок CODE-блока TAP: размер и адрес загрузки теперь считаются от `code_start`, а не от точки входа `start`.
- BASIC-loader по-прежнему запускает программу с метки `start`, но загружает весь машинный блок вместе с кодом и данными, расположенными перед ней.
- Это устраняет `R Tape loading error, 10:1`, появившийся после добавления 128K memory/paging кода.

## v0.0.6 -> v0.0.7

- BASIC-loader упрощён до одной строки: `LOAD "" CODE: RANDOMIZE USR <start>`.
- Переход к машинному коду теперь выполняется сразу после успешной загрузки CODE-блока, без перехода между BASIC-строками.
- Формат TAP, 128K target и машинный код не менялись.

## v0.0.7 -> v0.0.8

- Dev-запуск отвязан от Tape Loader: `./r` теперь открывает прямой 128K `.z80` snapshot.
- Добавлен `src/dev.asm`, который собирает raw-код фиксированного RAM bank 2 и сохраняет адрес точки входа `start`.
- Добавлен `tools/make_z80.py`: он формирует Z80 v3 snapshot с явным hardware mode Sinclair 128K, кодом в bank 2 и PC на `start`.
- `Makefile` собирает и `nightbus.tap` для реального железа, и `nightbus.z80` для Fuse.
- Из `r` удалены tape traps, phantom typist, autoload и вся магнитофонная автоматика.
- Удалён устаревший `snapshot.asm`.

## v0.0.8 -> v0.0.9

- Добавлен первый постоянный игровой цикл `main_loop`.
- Пунктирная горизонтальная линия теперь двигается по экрану сверху вниз.
- Добавлены подпрограммы `clear_screen`, `draw_line`, `wait_frame` и `move_line`.
- Анимация синхронизируется с прерываниями Spectrum через `HALT`, без программных busy-wait задержек.
- На этом учебном шаге добавлены `CALL`, `RET`, `HALT`, `EX DE,HL` и `ADD HL,DE`.
- Для понятности адреса 24 строк знакомест временно заданы таблицей; вычисление экранного адреса будет отдельным следующим уроком.
