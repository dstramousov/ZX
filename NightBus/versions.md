# Versions

## v0.0.0 -> v0.0.1

- Init repo

## v0.0.1 -> v0.0.2

- Подготовлена общая структура ZX как репозитория с независимыми подпроектами.
- Скрипт `a` теперь автоматически берёт имя текущего подпроекта и создаёт его архив по версии из локального `versions.md`.
- `appr` явно работает из корня подпроекта и показывает, чей `versions.md` используется для коммита общего ZX-репозитория.
- Добавлен `r`: сборка NightBus и запуск TAP в Fuse как ZX Spectrum 128K.
- В TAP добавлен BASIC-loader для автоматической загрузки машинного кода по адресу `$8000`.
- Добавлены README и корневой `.gitignore` для артефактов сборки и локальных архивов.

## v0.0.2 -> v0.0.3

- `a` и `appr` снова можно запускать прямо из корня `ZX`.
- Если подпроект пока один, он выбирается автоматически; при нескольких подпроектах используется `./a <project>` / `./appr <project>`.
- Сохранён запуск общих скриптов из корня подпроекта через `../a` / `../appr`.
- Git-команды `appr` теперь явно выполняются относительно корня общего репозитория `ZX`.

## v0.0.3 -> v0.0.4

- Для быстрого цикла разработки добавлен snapshot `build/nightbus.sna`.
- `sjasmplus` создаёт SNA напрямую из `src/main.asm` в режиме ZX Spectrum 48K.
- `./r` теперь запускает snapshot напрямую в Fuse, без зависимости от BASIC/TAP autoload.
- TAP остаётся частью обычной сборки и предназначен для запуска на реальном ZX Spectrum / ZX Evolution.

## v0.0.4 -> v0.0.5

- NightBus окончательно переведён на целевую платформу Sinclair ZX Spectrum 128K.
- 48K/SNA dev-запуск удалён: сборка снова использует TAP, чтобы не зависеть от неоднозначности 128K SNA в Fuse.
- `r` явно использует `128-0.rom` и `128-1.rom`, проверяет их наличие и запускает Fuse как машину `128`.
- Для автоматического запуска TAP включён 128K phantom typist в режиме меню; окно Fuse запускается с масштабом `3x`.
- Добавлены `memory.asm` и `paging.asm`: зафиксирована карта памяти и базовая процедура переключения RAM-банков через порт `$7FFD`.
- README приведён в соответствие с новой 128K-архитектурой.

## v0.0.5 -> v0.0.6

- Исправлен заголовок CODE-блока TAP: размер и адрес загрузки теперь считаются от `code_start`, а не от точки входа `start`.
- BASIC-loader по-прежнему запускает программу с метки `start`, но загружает весь машинный блок вместе с кодом и данными, расположенными перед ней.
- Это устраняет `R Tape loading error, 10:1`, появившийся после добавления 128K memory/paging кода.

## v0.0.6 -> v0.0.7

- BASIC-loader упрощён до одной строки: `LOAD "" CODE: RANDOMIZE USR <start>`.
- Переход к машинному коду теперь выполняется сразу после успешной загрузки CODE-блока, без перехода между BASIC-строками.
- Формат TAP, 128K target и машинный код не менялись.

## v0.0.7 -> v0.0.8

- Dev-запуск отвязан от Tape Loader: `./r` теперь открывает прямой 128K `.z80` snapshot.
- Добавлен `src/dev.asm`, который собирает raw-код фиксированного RAM bank 2 и сохраняет адрес точки входа `start`.
- Добавлен `tools/make_z80.py`: он формирует Z80 v3 snapshot с явным hardware mode Sinclair 128K, кодом в bank 2 и PC на `start`.
- `Makefile` собирает и `nightbus.tap` для реального железа, и `nightbus.z80` для Fuse.
- Из `r` удалены tape traps, phantom typist, autoload и вся магнитофонная автоматика.
- Удалён устаревший `snapshot.asm`.

## v0.0.8 -> v0.0.9

- Добавлен первый постоянный игровой цикл `main_loop`.
- Пунктирная горизонтальная линия теперь двигается по экрану сверху вниз.
- Добавлены подпрограммы `clear_screen`, `draw_line`, `wait_frame` и `move_line`.
- Анимация синхронизируется с прерываниями Spectrum через `HALT`, без программных busy-wait задержек.
- На этом учебном шаге добавлены `CALL`, `RET`, `HALT`, `EX DE,HL` и `ADD HL,DE`.
- Для понятности адреса 24 строк знакомест временно заданы таблицей; вычисление экранного адреса будет отдельным следующим уроком.

## v0.0.9 -> v0.0.10

- Вертикальное движение линии переведено с шага 8 пикселей на шаг 1 пиксель.
- `line_y` теперь работает во всём диапазоне экрана `0..191`.
- Добавлена `screen_address`, вычисляющая реальный адрес pixel row в нелинейной видеопамяти ZX Spectrum.
- Учебная таблица `line_addresses` удалена.
- Программная задержка пока сохранена; синхронизация с 50 Гц будет следующим отдельным этапом.

## v0.0.10 -> v0.0.11

- Исправлена формула `screen_address`: `Y2..Y0` теперь правильно попадают в младшие биты `H`.
- Движение синхронизировано с аппаратными прерываниями Spectrum (~50 Гц) через компактный IM2.
- Добавлен `interrupts.asm`; IM2 vector `$90FF` создаётся во время старта, без больших `ORG`-разрывов в binary.
- Стек перенесён в фиксированный bank 2 по адресу `$BFF0`.
- Полный bitmap очищается только один раз при старте; каждый кадр стираются и рисуются только 32 байта текущей линии.
- Линия перемещается ровно на 1 пиксель за кадр.

## v0.0.11 -> v0.0.12

- Исправлены циклы заполнения атрибутов и очистки bitmap.
- Удалена ошибочная схема `PUSH AF / OR / POP AF`: `POP AF` восстанавливал старые флаги и ломал условие `JR NZ`.
- Проверка 16-битного счётчика `BC` теперь сохраняет только значение `A`, но оставляет флаги результата `OR`.
- Frame sync, IM2 и формула `screen_address` не менялись.

## v0.0.12 -> v0.0.13

- Автоматическая линия заменена первым управляемым игровым маркером.
- Добавлены координаты `player_x` и `player_y` с диапазонами `0..255` и `0..191`.
- Добавлено чтение клавиатурной матрицы ZX Spectrum напрямую через порт `$FE`.
- Cursor-направления читаются через стандартные клавиши Spectrum `5/6/7/8`.
- Маркер двигается по одному пикселю за кадр и не выходит за границы экрана.
- Добавлены `pixel_mask`, `draw_player` и `erase_player` для адресации отдельного пикселя.
- 50 Гц frame sync из v0.0.12 сохранён без изменений.

## v0.0.13 -> v0.0.14

- Исправлены биты клавиш `7` и `6` в строке клавиатурной матрицы `$EFFE`.
- `UP` теперь читает bit 3 (`7`), `DOWN` — bit 4 (`6`).
- Горизонтальное управление и остальной игровой цикл не менялись.

## v0.0.14 -> v0.0.15

- Однопиксельный маркер заменён первым 8x8-спрайтом.
- Спрайт хранится как 8 последовательных байт bitmap-данных.
- Добавлен горизонтальный bit shift: спрайт корректно рисуется при любом `X`, а не только на границах 8 пикселей.
- Одна строка спрайта при необходимости раскладывается в два соседних экранных байта.
- Координаты ограничены `X=0..248`, `Y=0..184`, чтобы 8x8-спрайт не выходил за экран.
- Управление `5/6/7/8`, frame sync и IM2 оставлены без изменений.

## v0.0.15 -> v0.0.16

- Добавлены состояния `idle`, `walk A`, `walk B` для 8x8-персонажа.
- Горизонтальная ходьба анимируется сменой фазы примерно раз в 6 кадров при движении по 1 пикселю за кадр.
- Добавлено направление `player_facing`: вправо/влево.
- Для движения влево используются отдельные зеркальные кадры.
- При отпускании горизонтальной клавиши персонаж возвращается в idle.
- Вертикальное движение пока использует idle-кадр последнего горизонтального направления.

## v0.0.16 -> v0.0.17

- Moved player graphics out of `main.asm` into external 16x16 assets.
- Added five switchable player variants; variant 4 (coat + scarf) is default.
- Each variant has six 32-byte frames and native 16x16 PNG previews.
- Added `src/player_assets.asm`; only the selected 192-byte variant is included via `INCBIN`.
- Upgraded renderer from 8x8 to smooth 16x16 sub-byte movement.
- Movement bounds are now X=0..240 and Y=0..176.
- Runtime remains monochrome to avoid ZX Spectrum attribute clash during 1-pixel movement.
