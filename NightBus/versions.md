# Versions

## v0.0.0 -> v0.0.1

- Init repo

## v0.0.1 -> v0.0.2

- Подготовлена общая структура ZX как репозитория с независимыми подпроектами.
- Скрипт `a` теперь автоматически берёт имя текущего подпроекта и создаёт его архив по версии из локального `versions.md`.
- `appr` явно работает из корня подпроекта и показывает, чей `versions.md` используется для коммита общего ZX-репозитория.
- Добавлен `r`: сборка NightBus и запуск TAP в Fuse как ZX Spectrum 128K.
- В TAP добавлен BASIC-loader для автоматической загрузки машинного кода по адресу `$8000`.
- Добавлены README и корневой `.gitignore` для артефактов сборки и локальных архивов.

## v0.0.2 -> v0.0.3

- `a` и `appr` снова можно запускать прямо из корня `ZX`.
- Если подпроект пока один, он выбирается автоматически; при нескольких подпроектах используется `./a <project>` / `./appr <project>`.
- Сохранён запуск общих скриптов из корня подпроекта через `../a` / `../appr`.
- Git-команды `appr` теперь явно выполняются относительно корня общего репозитория `ZX`.

## v0.0.3 -> v0.0.4

- Для быстрого цикла разработки добавлен snapshot `build/nightbus.sna`.
- `sjasmplus` создаёт SNA напрямую из `src/main.asm` в режиме ZX Spectrum 48K.
- `./r` теперь запускает snapshot напрямую в Fuse, без зависимости от BASIC/TAP autoload.
- TAP остаётся частью обычной сборки и предназначен для запуска на реальном ZX Spectrum / ZX Evolution.
